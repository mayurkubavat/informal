# Security

InFormal is pre-release software. It parses design files and Tcl scripts
and runs external programs named in `config/engines.toml`, so only run
scripts and configurations you trust: an FPV script is a Tcl program with
full access to your account.

To report a vulnerability, use GitHub's private vulnerability reporting
on this repository (Security tab, "Report a vulnerability") instead of a
public issue. Fixes go into `main`; there are no maintained release
branches yet.
