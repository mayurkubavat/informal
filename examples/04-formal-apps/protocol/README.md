# Formal App Lab — Bus Protocol VIP (`check_protocol`)

Instantiates an APB4 slave protocol compliance suite (legal master assumptions, slave response safety assertions, and reachability covers) in one command:

```sh
informal shell examples/04-formal-apps/protocol/run.jg.tcl
```

InFormal also supports `-protocol axi4lite` and `-protocol tlul`, and roles `slave`, `master`, and `monitor`.
